# 🔥 Bonfire Radio | बोनफायर नाइट्स 

### 🎵 50's to 20's Music Player

Bonfire Radio is a vintage-style music player where you can discover music from the **1950s to the 2020s** and listen to **30-second previews**.

![Preview](./models/main.png)

## ✨ Features

* 🎵 30-second song previews
* 🔎 Search songs and artists
* 🎲 Random music discovery
* 📻 Browse by decade
* ❤️ Like your favorite songs
* 🎶 Add your own local music
* ⏭️ Previous / Next song
* ▶️ Auto-play next song
* 🖼️ Vintage + modern glass UI

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* iTunes Search API
